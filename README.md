# Quantum AI Based Drug Discovery Research

## Project Overview
This project explores computational drug discovery using Python, RDKit, and Quantum AI concepts.

## Research Goals
- Molecular structure analysis
- SMILES representation
- Molecular weight calculation
- LogP analysis
- Molecular fingerprint analysis
- Quantum machine learning exploration

## Day 01 – First Molecular Analysis
**Tools:** Python, RDKit, Google Colab

**Activities:**
- Molecular structure analysis
- SMILES processing
- Molecular descriptors calculation
- CSV results generation

## Files
- `Day01_Drug_Discovery_Research.ipynb` – Research notebook
- `Day01_Drug_Discovery_Results.csv` – Molecular analysis results

## Research Disclaimer
This is an educational computational research project. Predictions require experimental validation and do not establish clinical effectiveness.
